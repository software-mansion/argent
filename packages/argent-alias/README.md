# argent

This package is an alias for [`@swmansion/argent`](https://www.npmjs.com/package/@swmansion/argent),
so that you can run argent with a shorter command:

```sh
npx argent init
```

Every `argent` version runs the `@swmansion/argent` version with the same number.

To install argent globally, install `@swmansion/argent`. The alias refuses global installs:

```sh
npm install -g @swmansion/argent
```

See the [documentation](https://docs.swmansion.com/argent) for more.
