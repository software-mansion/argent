Argent runs and analyzes profiling sessions end to end:

- **React Native (Hermes)** CPU sampling,
- **React DevTools** render and commit profiling,
- **native** profiling through Xcode Instruments on iOS and Perfetto on Android.

Results come back as ranked reports, down to fiber renders, CPU hotspots and cross-correlated commit-versus-hang analysis, so you can ask for an optimization where it actually pays off.
