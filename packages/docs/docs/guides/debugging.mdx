title: Debugging and diagnostics
---

Your agent can inspect logs, capture network traffic (both JS `fetch` and native), evaluate JavaScript in the running app, walk the native UIKit and React component trees, and reproduce failing states.

For Electron and Chromium apps the same surface covers tabs, cookies, storage, the DOM and network traffic over the Chrome DevTools Protocol.
