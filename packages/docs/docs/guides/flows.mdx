title: Record and replay flows
---

A flow is a recorded sequence of interactions that can be replayed deterministically. Record a path once and manual repros, smoke tests and before-and-after comparisons become repeatable.

Flows are useful when:

- you are re-profiling after a fix and need the same path both times,
- you want an A/B comparison of two builds,
- a regression check needs to run the same steps on every branch,
- you just worked through a complex path worth keeping.
