# Debugging

Argent connects the agent to the JavaScript runtime of the running app. The agent reads the console logs, runs JavaScript in the app, and reads the component tree of the current screen. With this data the agent finds the cause of a bug without your help at the keyboard.

## Console logs

Argent collects the console output of the app. The agent reads a summary of the logs. The agent sees the warnings and the errors, their count, and their source. Thus the agent knows about a crash or a failed render before you describe it. The summary also contains the newest log lines. Thus the agent can read them without access to the log file.

When the app crashes, Argent keeps the log file of the session for at least 24 hours. The agent reads the logs from before the crash.

## Code evaluation

The agent runs JavaScript in the app to read a store, call a function, or change a value while the app stays open.
React Native apps, including supported [Mac apps](/docs/features/mac-apps#debug-a-react-native-app), use Hermes. Chromium and Electron apps use V8.

## Component trees

The agent reads the current screen as a text tree of React components. The agent also inspects the component at one point of the screen. Thus the agent sees which component renders an element, and which props the component receives.

The agent can inspect the native view tree on iOS and in AppKit-based [Mac apps](/docs/features/mac-apps). It can search by class or accessibility identifier and identify which view receives a tap or click. For Mac Catalyst apps, the agent reads UIKit controls through the accessibility tree.

## Network traffic

Ask the agent to find a failed HTTP request and inspect its response. See [Network inspection](/docs/features/network) for supported traffic and capture options.

## Chromium and Electron

For Chromium and Electron apps, Argent uses the Chrome DevTools Protocol. The agent lists the tabs, reads and writes cookies, and reads and writes the storage of the active page. The agent debugs the renderer of an Electron app in the same way as a web page.

## Reproduction

The agent reproduces a failed state. The agent restarts the app, reloads the Metro bundle, grants or resets a permission, or opens a URL. Then the agent does the steps again, and reads the logs and the component tree after each step.

## Example instructions

- "The profile screen shows an empty list. Find the cause."
- "Read the console errors after I tap the submit button."
- "Which component renders the red banner at the top of the screen?"
- "Print the content of the user store after the login."
- "This button does not react to a tap. Find the view that gets the touch."

## Limits

- In React Native apps that use React Native DevTools, Hermes sends its most recent logs to Argent when the debugger connects. The agent sees the logs from the start of the app, for example the warnings at launch.
- Hermes keeps 1000 logs at most. If the app writes more logs before the debugger connects, the agent does not see the oldest logs.
- In other apps, for example Chromium, Electron and Vega apps, Argent collects the logs from the moment the debugger connects. The agent does not see the earlier logs. Do the operation again after the agent connects.
- The agent connects to one app at a time.

Argent does this with the `debugger-*`, `native-*` and `chromium-*` tools. The [tools reference](/docs/reference/tools) contains all tools.
