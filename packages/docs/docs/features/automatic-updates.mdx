Argent checks for updates when the tool server starts and every 24 hours. By default, Argent updates a confirmed global installation in the background. Argent follows the minimum release age policy.

If your project declares the Argent version, the agent asks before updating it. The agent also asks when Argent cannot confirm which installation the package manager would update.

A background update leaves your workspace files and running session alone. The next MCP session uses the updated version. On the first tool call, the agent tells you what changed.

To ask before every update, run:

```bash
argent config set autoUpdate.enabled false
```

To turn off release highlights, run `argent disable whats-new`.

See the [configuration reference](/docs/reference/configuration) and the [tools reference](/docs/reference/tools).
