## Isolation

We assign each Mac to one customer. Each session on the Mac is its own operating system account on its own disk volume. A forward tunnel reaches only the servers that your own session started on the Mac.

## What survives a session

When a session returns to your team, Argent Cloud revokes its credentials, closes the live connections, erases every simulator, and rebuilds the session volume from a clean image. Your app binaries, simulator state and files do not survive the release. The reset takes about a minute.

## What Argent Cloud records

Argent Cloud does not record the screen video, the keystrokes or the app content. A screen recording that you start stays on the Mac until the session returns to your team. Argent Cloud keeps the operational logs of the Mac for 14 days.

## The API key

We issue one API key per user. Treat the key like a password and do not commit it to a repository.

`sim-remote login` reads the key from the `SIM_REMOTE_API_KEY` environment variable or from the `--api-key` option. Export the variable in your shell profile, in a `.envrc` file or in a secret manager. In CI, supply the variable as a secret.

`sim-remote` keeps the login token in the memory of the daemon. `sim-remote` writes no login token, API key or configuration file to disk. The [log files](/docs/cloud/reference/sessions#log-files) are the only files that `sim-remote` writes.

[GitHub Actions](/docs/cloud/integrations/github-actions#the-api-key) describes how the actions handle the key in a job.
