| Variable                          | Read by                   | Default                                                           | Purpose                                                                                   |
| --------------------------------- | ------------------------- | ----------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `SIM_ROUTER_API_KEY`              | `login`                   | None                                                              | The API key. Replaces `--api-key`                                                         |
| `SIM_ROUTER_URL`                  | All commands              | The URL in the release binary                                     | The Argent Cloud server. Replaces `--server`                                              |
| `SIM_REMOTE_IDLE_TIMEOUT_SECS`    | The daemon                | `900`                                                             | Seconds without a command before the daemon releases the machine                          |
| `SIM_REMOTE_SHIM_DIR`             | `install-shims`           | `$XDG_CACHE_HOME/sim-remote/shims` or `~/.cache/sim-remote/shims` | The directory of the Maestro and Appium stand-ins. The printed shell code also exports it |
| `SIM_REMOTE_BIN`                  | The stand-ins             | Set by the printed shell code                                     | The absolute path of the `sim-remote` binary that the stand-ins call                      |
| `SIM_REMOTE_SHIM_XCODE_VERSION`   | `install-shims`           | `26.0`                                                            | The Xcode version that the stand-in `Xcode.app` reports to Appium                         |
| `SIM_REMOTE_XCODE_SIM_DEV`        | The `xcodebuild` stand-in | The Xcode in `/Applications` on the machine                       | The Xcode location on the machine, used for the XCTest runtime                            |
| `SIM_REMOTE_FORCE_RUNNER_INSTALL` | The `xcodebuild` stand-in | Unset                                                             | Set to `1` to install the test runner on every run                                        |
| `RADON_LOG_DIR`                   | All commands              | See [Log files](/docs/cloud/reference/sessions#log-files)         | The log directory                                                                         |
| `RUST_LOG`                        | All commands              | Unset                                                             | The log filter                                                                            |

The shim variables are described in [Test driver shims](/docs/cloud/reference/shims).

A typical shell profile entry:

```bash
export SIM_ROUTER_API_KEY='...'
```

With this variable set, `sim-remote login` needs no arguments. A CI job supplies the same variable as a secret.
