## Client computers

`sim-remote` runs on these platforms:

| Platform | Architecture  | Notes                                                  |
| -------- | ------------- | ------------------------------------------------------ |
| macOS    | Apple Silicon |                                                        |
| Linux    | x86_64        | glibc 2.35 or newer (Ubuntu 22.04, Debian 12 or newer) |
| Linux    | arm64         | glibc 2.35 or newer (Ubuntu 22.04, Debian 12 or newer) |

## Hosted devices

Argent Cloud hosts these devices:

| Device           | Status        |
| ---------------- | ------------- |
| iOS simulator    | Supported     |
| Android emulator | Not available |
| Physical device  | Not available |

The device types and the iOS versions are the ones that Xcode on the Mac provides. Run this command to see them:

```bash
sim-remote simctl list devices available
```

A new session can start with one pre-booted iPhone simulator, so you do not wait for its first boot. You can create more simulators with `sim-remote simctl create`. A session stays responsive with up to two booted simulators, including the pre-booted one. See [Simulators per session](/docs/cloud/reference/sessions#simulators-per-session).
