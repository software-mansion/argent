Argent Cloud is a pool of isolated iOS simulators that run on dedicated Apple hardware. Each block of simulators runs on its own machine, so your simulators are never shared with anyone else. You control the simulators from your own computer with the `sim-remote` command line tool. Your computer does not need Xcode, and it does not need to be a Mac.

## Quick start with an AI agent

```text
Set up Argent Cloud on this computer and boot a hosted iOS simulator.

Follow the documentation at https://docs.swmansion.com/argent/docs/cloud/fundamentals/installation.

1. Download the latest sim-remote binary for this platform from
   https://github.com/software-mansion/sim-remote-releases/releases/latest,
   make it executable and put it in ~/.local/bin. Add ~/.local/bin to PATH if it is missing.
2. Confirm the installation with `sim-remote --help`.
3. Export SIM_ROUTER_API_KEY=<my api key> in this shell only. Do not write the key to any file.
4. Run `sim-remote login` and wait until it prints the acquired machine.
5. Run `sim-remote simctl list devices available` and pick an iPhone.
6. Boot it with `sim-remote simctl boot <UDID>` and wait with `sim-remote simctl bootstatus <UDID> -b`.
7. Report the machine name, the UDID and the state of the simulator.

Do not run `sim-remote logout`. I want to keep the machine.
```

## Your first session

1. [Install](/docs/cloud/fundamentals/installation) `sim-remote` and put your API key in the `SIM_ROUTER_API_KEY` variable.
2. Log in. The command reserves a machine for you and prints its name.

   ```bash
   sim-remote login
   ```

3. List the simulators on your machine and copy the UDID of one of them.

   ```bash
   sim-remote simctl list devices available
   ```

4. Boot the simulator.

   ```bash
   sim-remote simctl boot <UDID>
   ```

5. Wait until the boot completes.

   ```bash
   sim-remote simctl bootstatus <UDID> -b
   ```

6. Install your app. The path is a path on your computer. `sim-remote` uploads the bundle for you.

   ```bash
   sim-remote simctl install <UDID> ./build/MyApp.app
   ```

7. Launch your app.

   ```bash
   sim-remote simctl launch <UDID> com.example.MyApp
   ```

8. Log out when you are done. The command returns the machine to your team.

   ```bash
   sim-remote logout
   ```
