Argent Cloud is a platform from Software Mansion that hosts isolated iOS simulators on dedicated Apple hardware. AI coding agents, such as Claude Code or Cursor Cloud Agents, use these simulators to run, inspect, debug and test iOS and React Native apps. CI pipelines on Linux use them in the same way.

## Quick start

### Step 1: Install the `sim-remote` CLI

<InstallCommand />

If `~/.local/bin` is not on your `PATH`, add this line to your shell profile and run it in the current shell:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

Confirm the installation:

```bash
sim-remote --help
```

See [Installation](/docs/cloud/fundamentals/installation) for the prerequisites and the list of release assets.

### Step 2: Acquire an API key

We issue one API key per user. If you do not have a key, [contact us](https://argent.swmansion.com/cloud#contact). Treat the key like a password. See [Security and data](/docs/cloud/reference/security-and-data).

### Step 3: Authenticate

Put your API key in the `SIM_REMOTE_API_KEY` environment variable and log in. `sim-remote login` reserves a session for you and prints its ID.

```bash
export SIM_REMOTE_API_KEY=<API_KEY>
sim-remote login
```

Set the variable once in your shell profile. In CI, supply it as a secret. You can also pass the key with the `--api-key` option:

```bash
sim-remote login --api-key <API_KEY>
```

### Step 4: Boot a simulator

List the simulators in your session and copy the UDID of one of them.

```bash
sim-remote simctl list devices available
```

Boot the simulator and wait until the boot completes. The `-b` option boots the simulator if it is not booted yet.

```bash
sim-remote simctl bootstatus <UDID> -b
```

### Step 5: Install and launch your app

Install your app from a path on your computer. `sim-remote` uploads the bundle for you.

```bash
sim-remote simctl install <UDID> ./build/MyApp.app
```

Launch your app.

```bash
sim-remote simctl launch <UDID> com.example.MyApp
```

### Step 6: Log out

Log out when you are done. Other users on your team can then use the session.

```bash
sim-remote logout
```
