Argent Cloud runs iOS simulators on hosted macOS machines. Each machine is reserved for one user at a time, so your simulators are never shared with anyone else. You control the simulators from your own computer with the `sim-remote` command line tool. Your computer does not need Xcode, and it does not need to be a Mac.

## Quick start

### Step 1: Install the `sim-remote` CLI

<InstallCommand />

If `~/.local/bin` is not on your `PATH`, add this line to your shell profile:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

Confirm the installation:

```bash
sim-remote --help
```

See [Installation](/docs/cloud/fundamentals/installation) for the prerequisites and the list of release assets.

### Step 2: Acquire an API key

We issue one API key per user and send it to you directly. If you do not have a key yet, [contact us](https://argent.swmansion.com/cloud#contact) and we will send you one. Treat the key like a password and do not commit it to a repository.

### Step 3: Authenticate

Put your API key in the `SIM_ROUTER_API_KEY` variable and log in. The command reserves a machine for you and prints its name.

```bash
export SIM_ROUTER_API_KEY=<your key>

sim-remote login
```

`sim-remote` keeps the session in memory only and does not write the key to disk.

### Step 4: Boot a simulator

List the simulators on your machine and copy the UDID of one of them.

```bash
sim-remote simctl list devices available
```

Boot the simulator and wait until the boot completes.

```bash
sim-remote simctl boot <UDID>
sim-remote simctl bootstatus <UDID> -b
```

### Step 5: Install and launch your app

Install your app. The path is a path on your computer. `sim-remote` uploads the bundle for you.

```bash
sim-remote simctl install <UDID> ./build/MyApp.app
```

Launch your app.

```bash
sim-remote simctl launch <UDID> com.example.MyApp
```

### Step 6: Log out

Log out when you are done. The command returns the machine to your team.

```bash
sim-remote logout
```
