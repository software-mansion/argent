Argent Cloud has three parts. The `sim-remote` CLI runs on your computer. The Argent Cloud server checks your API key and assigns machines. A hosted Mac runs the iOS simulators. The CLI sends each command to the machine and prints the result. The simulator has no window on your screen. You see it through screenshots, screen recordings or Argent.

## Sessions and machines

A session is your authenticated connection to Argent Cloud. A machine is a hosted Mac that Argent Cloud reserves for your session. `sim-remote` manages the two separately. You can keep a machine across shells, hand it to another client, or give it back without a logout. See [Manage machines](/docs/cloud/guides/machines).

## The daemon

`sim-remote` runs a small background daemon on your computer. The daemon holds the session token in memory, sends a heartbeat to the server, and owns the tunnels. Any command that needs a session starts the daemon. If you send no command for 15 minutes, the daemon releases the machine on its own. The [sessions and limits reference](/docs/cloud/reference/sessions) lists the timeouts.

## Simulator control

`sim-remote simctl` is a stand-in for `xcrun simctl`. The command has the same subcommands, the same arguments, the same output and the same exit codes. A file path from your computer means nothing on the hosted machine. For this reason, `sim-remote` runs the subcommands that name a file on its own. It uploads the file for `install`, `addmedia` and `push`, and downloads the result for `io screenshot`, `io recordVideo` and `get_app_container`. All other subcommands go to the machine without changes. See [Run your app](/docs/cloud/guides/run-your-app).

## Networking

Your computer and the hosted simulator are on different networks. Neither side can reach the `localhost` of the other. A reverse tunnel lets the simulator reach a server on your computer. A forward tunnel lets your computer reach a server on the machine. The daemon keeps the tunnels open between commands. See [Connect to local servers](/docs/cloud/guides/local-servers).

The [CLI reference](/docs/cloud/reference/cli) lists all commands.
