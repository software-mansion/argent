This page is the conceptual overview of Argent Cloud. Each feature has its own page.

## Hosted simulators

Argent Cloud runs iOS simulators on hosted macOS machines. The `sim-remote simctl` command is a stand-in for `xcrun simctl`. Your scripts and your tools work without changes. See [Hosted simulators](/docs/cloud/features/hosted-simulators).

## Sessions and machines

When you log in, `sim-remote` reserves a machine for you. You keep the machine until you release it or until it is idle for too long. See [Sessions and machines](/docs/cloud/features/sessions).

## Tunnels

Your computer and the hosted simulator are on different networks. Tunnels connect a port on one side to a port on the other side. A hosted simulator can load a bundle from your local Metro server. See [Tunnels](/docs/cloud/features/tunnels).

## Integrations

Argent, Maestro, Appium and GitHub Actions work with the hosted simulators. See [Integrations](/docs/cloud/integrations/argent).

The [reference](/docs/cloud/reference/overview) contains the technical details.
