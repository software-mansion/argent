Argent Cloud runs the iOS simulators on a hosted macOS machine. You control them from your computer with `sim-remote simctl`. The command has the same subcommands, the same arguments, the same output and the same exit codes as `xcrun simctl`.

## A stand-in for `xcrun simctl`

`sim-remote` sends the arguments of `simctl` to the machine and prints the result. A script that uses `xcrun simctl` works on a hosted simulator when you add the `sim-remote` prefix.

```bash
sim-remote simctl list devices --json | jq '.devices'
sim-remote simctl launch --console <UDID> com.example.MyApp
```

The `simctl help` command shows the documentation of Apple for each subcommand:

```bash
sim-remote simctl help launch
```

## Local files

A file path from your computer means nothing on the hosted machine. For this reason, `sim-remote` handles the subcommands that use a file on its own:

- `install`, `install_app_data`, `addmedia`, `push` and `keychain add-cert` upload your file to the machine.
- `io screenshot`, `io recordVideo` and `get_app_container` download the result to your computer.
- `pbcopy` and `pbsync` move the clipboard content between your computer and the simulator.

All other subcommands go to the machine without changes.

## Example instructions

- "Boot the hosted iPhone and install the build from `./build/MyApp.app`."
- "Take a screenshot of the hosted simulator and save it as `shot.png`."
- "Send the push payload from `./payload.apns` to the app on the hosted simulator."
- "Open the deep link `myapp://profile` on the hosted simulator."

## Limits

- Argent Cloud hosts iOS simulators only. See [Supported platforms](/docs/cloud/fundamentals/supported-platforms).
- The hosted simulator has no window on your screen. Use screenshots, screen recordings or Argent to see it.
- One upload is at most 1 GiB.
- `sim-remote` does not add new options to the subcommands that it handles on its own. If you pass an unsupported option, `sim-remote` prints an error that names the accepted form.

The [simctl reference](/docs/cloud/reference/simctl) lists every subcommand that `sim-remote` handles on its own. The [CLI reference](/docs/cloud/reference/cli) lists all commands.
